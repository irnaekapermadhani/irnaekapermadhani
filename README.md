# Website Profil — Irna Eka Permadhani

Website profil pribadi dengan tema pink soft, elegan, dan responsif.

## Isi folder
- `index.html` — struktur halaman website
- `style.css` — desain, warna, dan tampilan responsif
- `script.js` — interaksi menu dan tahun otomatis
- `assets/makeup.svg` — ilustrasi galeri makeup
- `assets/art.svg` — ilustrasi galeri kesenian

## Cara memasang di GitHub Pages
1. Ekstrak file ZIP ini.
2. Buka GitHub dan buat repository baru (misalnya `profil-irna`).
3. Upload semua file dan folder di dalam ZIP ke bagian utama repository (root), bukan mengupload file ZIP-nya saja.
4. Pastikan `index.html` berada sejajar dengan `style.css` dan `script.js`.
5. Buka **Settings → Pages**.
6. Pada **Build and deployment**, pilih **Deploy from a branch**.
7. Pilih branch **main** dan folder **/(root)**, lalu klik **Save**.
8. Tunggu beberapa menit, kemudian buka alamat GitHub Pages yang muncul di bagian Pages.

## Mengganti gambar galeri
Ganti file `assets/makeup.svg` dan `assets/art.svg` dengan gambar milik sendiri. Jika memakai JPG/PNG, ubah juga nama file pada atribut `src` di `index.html`.

## Privasi
Nomor HP, email pribadi, dan alamat rumah lengkap sengaja tidak dipublikasikan pada halaman ini. Untuk website publik, lebih aman menggunakan kontak khusus yang memang disiapkan untuk umum dan hanya mencantumkan domisili secara umum.
